# Social Media App

A social media feed application built with React.js that displays posts, user information, and hashtags in an organized interface.

## Features

- Display posts with titles and descriptions.
- Show post views and user information.
- Organize posts using hashtags.
- Manage and display post data dynamically.
- Component-based React architecture.

## Tech Stack

- React.js
- JavaScript
- HTML
- CSS
- Vite

## Run Locally

```bash
npm install
npm run dev
```

Open the local URL displayed by Vite in your browser.
